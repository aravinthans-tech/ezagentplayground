API key

Generate a single customer API key. JWT stays internal.

  • EndpointsPOST /api/Client/apiKey, GET /api/Client/apiKey
  • QueryuserName, password, optional tenantId
  • ResponsetenantName, apiKey, expiresAt

Workflow List

List all workflows available in the selected tenant.

  • WrapperGET /api/v6/workflows
  • HeadersX-API-Key

Initiate Request

Client sends workflowName. Playground resolves the workflow ID, then starts the ticket (multipart).

  • WrapperPOST /api/v6/workflows/start
  • FieldsworkflowName, file, context, envType

Move Transaction

Client sends workflowName. Playground resolves workflowId and moves the ticket to the next step.

  • WrapperPOST /api/v6/workflows/instances/{instanceId}/move-next
  • BodyworkflowName, activityid, optional review / comments

Upload File To Repository

Single function: load repository fields, OCR the file (uploadForOcr), map ocrFieldList to metadata, then archive (upload-archive).

  • WrapperPOST /api/v6/repositories/upload-file
  • FieldsrepositoryName, file, optional ocrType / pageNo
  • OCR fieldsAuto-built from repository field definitions (e.g. ["Supplier, SHORT_TEXT","InvoiceDate, DATE"])
  • V6 stepsGET /api/repositories/{id} → POST /api/uploadAndIndex/uploadForOcr → POST /api/repositories/{id}/items/upload-archive

Download File From Repository

List files in a repository, then download one by item ID.

  • WrapperGET /api/v6/repositories/{repositoryId}/items/{itemId}/file
  • Querydisposition=attachment (download) or inline
  • List filesGET /api/v6/repositories/{repositoryId}/items

Repository Filter

Click a repository, then a filter field (e.g. Supplier), then a value, then see matching files.

  • FiltersGET /api/v6/repositories/{id}/items/filter-fields
  • ValuesGET /api/v6/repositories/{id}/items/facets/{fieldName}
  • FilesPOST /api/v6/repositories/{id}/items/query body { "filters": { "Supplier": ["ACME"] } }
