API key

Get a playground API key and Ezofis token first. Other APIs use these credentials.

  • EndpointsPOST /api/Client/apiKey, GET /api/Client/apiKey
  • QueryuserName, password
  • AuthNo X-API-Key header on this route
Sample request 
POST /api/Client/apiKey?userName=admin@ezofis.com&password=your_password
Sample response 
{
  "tenantId": "123",
  "token": "eyJhbGciOi...",
  "apiKey": "x4iDIG6..."
}

Form Details

Fetch forms with filters, sorting, and pagination. Optional request/response encryption.

  • EndpointPOST /api/FormDetails
  • HeadersX-API-Key, Ezofis-Token
Sample body 
{
  "query": {
    "filterBy": "",
    "sortBy": "formId desc",
    "pageNo": 1,
    "pageSize": 10
  },
  "useEncryptedRequest": true,
  "useEncryptedResponse": true
}

Success returns id: 1 and JSON in output (or encrypted content when flags are set).

SubForm Details

List subform/panel titles for a form. Use exact titles in SubForm Fields.

  • EndpointPOST /api/SubFormDetails
  • HeadersX-API-Key, Ezofis-Token
Sample body 
{ "formId": 139 }

Use returned subform titles exactly when calling /api/SubFormFields.

SubForm Fields

Field metadata for one or more subform titles.

  • EndpointPOST /api/SubFormFields
  • HeadersX-API-Key, Ezofis-Token
Sample body 
{
  "formId": 139,
  "subforms": ["009 - Account Details"]
}

Generate PDF

Submit subform values and generate archive/PDF in one call.

  • EndpointPOST /api/SubFormSubmitAndArchive
  • HeadersX-API-Key, Ezofis-Token
Sample body 
{
  "formId": 139,
  "templateId": 132,
  "entryIdForFormEntry": 0,
  "entryId": 0,
  "isMultiple": false,
  "panelName": "009 - Account Details",
  "fields": { "ed3dZq8mL_6QgGV26PAJj": "123456" }
}

Required: formId, templateId, panelName, fields.

Access2Pay Connector Insert

Insert a connector payload into Access2Pay. Only X-API-Key is required from the client; tenant token is applied server-side.

  • EndpointPOST /api/Access2Pay/connectorInsert
  • HeadersX-API-Key
Sample body 
{
  "connectorId": 89,
  "payload": {
    "processId": 26,
    "workflowId": 104,
    "transactionId": 26,
    "formId": 141,
    "transactionStatus": "Pending",
    "formentryId": 27,
    "requestPayLoad": {
      "referenceNo": "REQ-28",
      "submission": { "submittedFrom": "muthu.perumal@ezofis.com", "emailSubject": "..." },
      "sourceDocument": { "fileName": "_20260604140429723.pdf", "mimeType": "application/pdf", "location": "https://..." },
      "Vendor": { "company": "Maple Leaf Logistics Inc." },
      "Invoice": {
        "invoiceNumber": "INV-2026-004",
        "currency": "CAD",
        "lineItems": [{ "lineNumber": 1, "description": "...", "lineAmount": "1495.00" }]
      }
    }
  }
}

The playground proxies to Ezofis with the connector body sent as a JSON-encoded string.

Access2Pay Get

Browse Access2Pay records with sorting, pagination, and filters.

  • EndpointPOST /api/Access2Pay/get
  • HeadersX-API-Key
Sample body 
{
  "sortBy": { "criteria": "id", "order": "DESC" },
  "filterBy": [
    {
      "groupCondition": "",
      "filters": [
        { "criteria": "referenceNo", "condition": "IS_EQUALS_TO", "value": "EZ-00012" }
      ]
    }
  ],
  "currentPage": 1,
  "itemsPerPage": 0,
  "mode": "browse"
}

Use filterBy to search records. Leave filterBy as [] to return all rows for the current page.

Access2Pay Update

Update an existing Access2Pay record by ID.

  • EndpointPUT /api/Access2Pay/update/{id}
  • HeadersX-API-Key
Sample body 
{
  "referenceNo": "EZ-00012",
  "transactionStatus": "processed"
}

The update payload is sent as a JSON-encoded string to the upstream API.
