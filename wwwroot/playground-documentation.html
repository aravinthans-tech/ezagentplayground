API key

Generate a single customer API key. JWT stays internal.

  • EndpointsPOST /api/Client/apiKey, GET /api/Client/apiKey
  • QueryuserName, password, optional tenantId
  • ResponsetenantName, apiKey, expiresAt

Workflow List

List all workflows available in the selected tenant.

  • WrapperGET /api/v6/workflows
  • HeadersX-API-Key

Initiate Request

Client sends workflowName. Playground resolves the workflow ID, then starts the ticket (multipart).

  • WrapperPOST /api/v6/workflows/start
  • FieldsworkflowName, file, context, envType

Advance Workflow

Client sends workflowName. Playground resolves workflowId and moves the ticket to the next step.

  • WrapperPOST /api/v6/workflows/instances/{instanceId}/move-next
  • BodyworkflowName, activityid, optional review / comments
