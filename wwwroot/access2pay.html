InitiateProcess

Call POST /api/Access2Pay/InitiateProcess

Request

If set, request payload JSON is POSTed to this URL before the response returns.

Use filterBy to search records. Example — replace [] with:

[
  {
    "groupCondition": "",
    "filters": [
      { "criteria": "referenceNo", "condition": "IS_EQUALS_TO", "value": "EZ-00012" }
    ]
  }
]

referenceNo is required — record id is resolved server-side.
