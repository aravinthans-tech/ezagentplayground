Download File From Repository

Pick a repository and file, then download via GET /api/v6/repositories/{id}/items/{itemId}/file

Request

Repositories load for this API key’s tenant.

Files load from the selected repository.

Wrapper: GET /api/v6/repositories/{repositoryId}/items/{itemId}/file

Response

Download to save the file to your computer.
